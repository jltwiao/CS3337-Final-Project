# How to setup
1. Navigate to your original bookEx folder and move the `db.sqlite3` to somewhere temporary 
2. Either move your bookEx elsewhere or rename it to like `bookEx-old`. 
3. Clone the repository to where your original bookEx was
```git
git clone https://github.com/jltwiao/CS3337-Final-Project
```
or with SSH
```git
gi clone git@github.com:jltwiao/CS3337-Final-Project.git
```
4. Include the `db.sqlite3` in the bookEx (this is where your login are)
Now in PyCharm you should see the git stuff show on the top right, make sure you have the Ultimate version of PyCharm (by signing up here https://www.jetbrains.com/academy/student-pack/) and log into your Jetbrains account from Pycharm.
